One emoji, one smile: 🥲 — a smiling face with a single tear. Not the
generic grin thousands of entries send, but a smile with a story behind it:
someone so touched by a small kindness that they smile through happy tears.
The tear is what makes the warmth real. The program writes exactly that one
emoji to `/output/entry.txt` and reads it back to verify it — nothing else,
no words, no caption, no explanation, just as the bounty asks.

## Run it

```sh
python3 main.py
```
